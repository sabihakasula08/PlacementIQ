# PlacementIQ – Smart Campus Placement Management System

A Python-based desktop application designed to simplify and manage campus placement activities.

## Features
- Student Management
- Placement Readiness Scoring
- Skill Gap Analysis
- Smart Eligibility Checking
- Placement Drive Management
- Application Tracking
- Placement Analytics

## Technologies Used
- Python
- Tkinter
- SQLite

## Application Type
Desktop Application Development – Mini Project

## How to Run
1. Install Python.
2. Download or clone this repository.
3. Install any required dependencies.
4. Run the main Python file.

## Project Purpose
To simplify campus placement management and help students understand their placement readiness and eligibility for job opportunities.
